# Aprendiendo GitHub

## Objetivo
Aprender a utilizar GitHub para gestionar proyectos
y colaborar con otros desarrolladores.

## Temas de práctica
- Repositorios
- Commits
- Issues
- Branches
- Pull Requests

## Mi primer proyecto
Este repositorio forma parte de mi aprendizaje de Git y GitHub.


## Flujo de colaboración

1. Crear una rama para cada mejora.
2. Realizar y guardar los cambios.
3. Abrir un Pull Request.
4. Revisar los cambios antes de integrarlos en main.


## Flujo de trabajo del proyecto

Los cambios nuevos deben desarrollarse en ramas independientes y proponerse mediante Pull Requests.
